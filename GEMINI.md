# СМАЧНО

A mobile-first web application for ordering food.

## Tech Stack
- **Framework**: React + Vite
- **Language**: JavaScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Package Manager**: Bun

## Features
- Mobile-first UI
- Bottom Navigation (Menu, Cart, Contacts)
- Russian Localization
